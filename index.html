Day 1 — Abstract Algebra Foundations
Definition
Factor Ring (Quotient Ring)
Also called: factor ring, residue class ring
Formal Definition

Let $(R, +, \cdot)$ be a ring and $I \subseteq R$ a two-sided ideal. The factor ring (or quotient ring) $R/I$ is the set of all cosets of $I$ in $(R, +)$:

$$R/I = \{ a + I \mid a \in R \} = \{ \{a + x \mid x \in I\} \mid a \in R \}$$

with operations defined as:

  • Addition: $(a + I) + (b + I) = (a + b) + I$
  • Multiplication: $(a + I)(b + I) = (ab) + I$

Why is this well-defined?

The operations must not depend on the choice of representative. We must check: if $a + I = a' + I$ and $b + I = b' + I$, then $(a+b)+I = (a'+b')+I$ and $ab+I = a'b'+I$.

Verification (multiplication)

$a' = a + i_1$, $b' = b + i_2$ for some $i_1, i_2 \in I$. Then:

$$a'b' = (a+i_1)(b+i_2) = ab + ai_2 + i_1 b + i_1 i_2$$

Since $I$ is a two-sided ideal: $ai_2 \in I$, $i_1 b \in I$, $i_1 i_2 \in I$. So $a'b' - ab \in I$, thus $a'b' + I = ab + I$. ✓

What is an ideal?

Ideal

A subset $I \subseteq R$ is a two-sided ideal if:

  • $(I, +)$ is a subgroup of $(R, +)$
  • For all $r \in R$, $i \in I$: $ri \in I$ and $ir \in I$ (absorption)
Key Example

$\mathbb{Z}/n\mathbb{Z}$: Take $R = \mathbb{Z}$, $I = n\mathbb{Z} = \{nk : k \in \mathbb{Z}\}$. Then:

$$\mathbb{Z}/n\mathbb{Z} = \{\bar{0}, \bar{1}, \bar{2}, \ldots, \overline{n-1}\}$$

where $\bar{a} = a + n\mathbb{Z}$ is the residue class of $a$. For $n=5$: $\bar{3} + \bar{4} = \bar{2}$, $\bar{3} \cdot \bar{4} = \bar{2}$.

$\mathbb{Z}[x]/(x^2+1)$: Every element is $a + bx$ (polynomial mod $x^2+1$, since $x^2 \equiv -1$). This is actually $\mathbb{C}$, the complex numbers!

Exam tip

Be ready to: (1) state the definition with formal set notation, (2) define the two operations, (3) explain why well-definedness requires $I$ to be an ideal (not just a subgroup), (4) give the $\mathbb{Z}/n\mathbb{Z}$ example.

Definition
Integral Domain (Integrity Field)
Formal Definition

A commutative ring $(R, +, \cdot)$ with unity $1 \neq 0$ is an integral domain if it has no zero divisors:

$$\forall a, b \in R: \quad ab = 0 \implies a = 0 \text{ or } b = 0$$

Equivalently: the cancellation law holds: $ab = ac$ and $a \neq 0 \implies b = c$.

Full hierarchy of algebraic structures

StructureWhat it adds
Ring$(R,+)$ abelian group, multiplication associative, distributive
Commutative ring$ab = ba$
Ring with unity$\exists 1 \in R: 1 \cdot a = a$

FieldIntegral domain + every non-zero element has a multiplicative inverse
Examples

Integral domains: $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$, $\mathbb{Z}[x]$, $\mathbb{Z}[i]$ (Gaussian integers)

Not integral domains: $\mathbb{Z}/6\mathbb{Z}$ — because $2 \cdot 3 = 6 \equiv 0$ but $2 \neq 0$ and $3 \neq 0$. Zero divisors!

Important Theorem

$\mathbb{Z}/n\mathbb{Z}$ is an integral domain if and only if $n$ is prime. In that case it is also a field (since every finite integral domain is a field).

Definition
Principal Ideal Domain (PID)
Czech: obor hlavních ideálů
Formal Definition

An integral domain $R$ is a principal ideal domain (PID) if every ideal of $R$ is principal, i.e., generated by a single element:

$$\forall I \subseteq R \text{ ideal}: \quad \exists a \in R \text{ such that } I = (a) = aR = \{ar : r \in R\}$$

Principal ideal — what does it mean?

The ideal generated by $a$ is $(a) = \{ra : r \in R\}$, all multiples of $a$. In $\mathbb{Z}$: $(6) = \{\ldots, -12, -6, 0, 6, 12, \ldots\}$.

Key Examples

$\mathbb{Z}$ is a PID: Every ideal is $(n)$ for some $n \geq 0$. Proof: take the smallest positive element of any ideal.

$F[x]$ is a PID for any field $F$: Use polynomial division to show every ideal is generated by the GCD polynomial.

$\mathbb{Z}[x]$ is NOT a PID: The ideal $(2, x)$ (polynomials with even constant term) is not principal.

Hierarchy

Euclidean domain $\implies$ PID $\implies$ UFD (unique factorization domain) $\implies$ Integral domain. None of these implications reverses in general.

Exam tip

The exam often uses "field of principal ideals" to mean PID. Know the definition, one non-example, and the fact that $F[x]$ is always a PID.

Definition
Characteristic of a Ring
Formal Definition

The characteristic of a ring $R$ with unity $1$ is the smallest positive integer $n$ such that:

$$\underbrace{1 + 1 + \cdots + 1}_{n} = 0$$

If no such $n$ exists, we write $\text{char}(R) = 0$.

Equivalently: $\text{char}(R) = \min\{n \in \mathbb{N} : n \cdot 1_R = 0\}$, where $n \cdot a = \underbrace{a + a + \cdots + a}_n$.

Key Theorem

The characteristic of an integral domain (and thus any field) is either $0$ or a prime $p$.

Proof

Suppose $\text{char}(R) = n = ab$ with $1 < a, b < n$. Then $(a \cdot 1)(b \cdot 1) = (ab) \cdot 1 = n \cdot 1 = 0$. Since $R$ is an integral domain, $a \cdot 1 = 0$ or $b \cdot 1 = 0$. But this contradicts the minimality of $n$. So $n$ must be prime. $\square$

Examples
  • $\text{char}(\mathbb{Z}) = \text{char}(\mathbb{Q}) = \text{char}(\mathbb{R}) = \text{char}(\mathbb{C}) = 0$
  • $\text{char}(\mathbb{Z}/p\mathbb{Z}) = p$ (prime)
  • $\text{char}(\text{GF}(p^k)) = p$
  • $\text{char}(\mathbb{Z}/6\mathbb{Z}) = 6$ — but this is not an integral domain
Frobenius Endomorphism (char p)

If $R$ has characteristic $p$ (prime), then for all $a, b \in R$:

$$(a + b)^p = a^p + b^p$$

This is because the binomial coefficients $\binom{p}{k}$ for $0 < k < p$ are all divisible by $p$, hence zero in characteristic $p$.

Definition
Field Extension (Body Extension)
Formal Definition

If $F$ and $K$ are fields and $F \subseteq K$ (with the same operations), we say $K$ is a field extension of $F$, written $K/F$ (read "K over F").

The degree of the extension is $[K:F] = \dim_F(K)$ — the dimension of $K$ as a vector space over $F$.

Types of extensions

  • Simple extension: $K = F(\alpha)$ — generated by adjoining a single element $\alpha$
  • Algebraic extension: every element of $K$ is a root of some polynomial in $F[x]$
  • Finite extension: $[K:F] < \infty$ (every finite extension is algebraic)
Examples
  • $\mathbb{C}/\mathbb{R}$: degree 2, basis $\{1, i\}$
  • $\mathbb{Q}(\sqrt{2})/\mathbb{Q}$: degree 2, basis $\{1, \sqrt{2}\}$
  • $\text{GF}(p^k)/\text{GF}(p)$: degree $k$, basis $\{1, \alpha, \alpha^2, \ldots, \alpha^{k-1}\}$ where $\alpha$ is a root of an irreducible degree-$k$ polynomial over $\text{GF}(p)$
Tower Law

If $F \subseteq E \subseteq K$ are fields, then $[K:F] = [K:E] \cdot [E:F]$.

Minimal polynomial

For an algebraic element $\alpha$ over $F$, the minimal polynomial $\text{min}_F(\alpha)$ is the unique monic irreducible polynomial in $F[x]$ with $\alpha$ as a root. Then $F(\alpha) \cong F[x]/(\text{min}_F(\alpha))$ and $[F(\alpha):F] = \deg(\text{min}_F(\alpha))$.

Theorem + Proof
Kernel of a Homomorphism is a Normal Subgroup
Theorem Statement

Let $\varphi: G \to H$ be a group homomorphism. Then $\ker(\varphi) = \{g \in G : \varphi(g) = e_H\}$ is a normal subgroup of $G$.

Definitions you need

Group homomorphism

A map $\varphi: G \to H$ such that $\varphi(ab) = \varphi(a)\varphi(b)$ for all $a, b \in G$.

Normal subgroup

A subgroup $N \leq G$ is normal ($N \trianglelefteq G$) if for all $g \in G$: $gNg^{-1} = N$, i.e., $gng^{-1} \in N$ for all $n \in N$.

Proof — Step by Step

Let $K = \ker(\varphi)$. We prove two things: (1) $K$ is a subgroup, (2) $K$ is normal.

Step 1: $K$ is a subgroup.

  1. Non-empty / identity: $\varphi(e_G) = e_H$ (homomorphisms always send identity to identity: $\varphi(e_G) = \varphi(e_G \cdot e_G) = \varphi(e_G)\varphi(e_G)$, cancel $\varphi(e_G)$). So $e_G \in K$. ✓
  2. Closure: Let $a, b \in K$. Then $\varphi(ab) = \varphi(a)\varphi(b) = e_H \cdot e_H = e_H$. So $ab \in K$. ✓
  3. Inverses: Let $a \in K$. Then $\varphi(a^{-1}) = \varphi(a)^{-1} = e_H^{-1} = e_H$. So $a^{-1} \in K$. ✓

Step 2: $K$ is normal in $G$.

We must show: for all $g \in G$ and $n \in K$, we have $gng^{-1} \in K$.

$$\varphi(gng^{-1}) = \varphi(g)\,\varphi(n)\,\varphi(g^{-1}) = \varphi(g) \cdot e_H \cdot \varphi(g)^{-1} = \varphi(g)\varphi(g)^{-1} = e_H$$

Therefore $gng^{-1} \in K$. Since $g$ and $n$ were arbitrary, $K \trianglelefteq G$. $\square$

Exam tip — perfect description means:

1. State the homomorphism property. 2. Define the kernel. 3. Prove subgroup (3 parts). 4. Prove normality using the computation above. Each line should be justified.

Day 2 — Finite Fields GF(p^k)
Definition
GF(p^k) — Galois Field
Not in lectures — source it carefully
Formal Definition

For a prime $p$ and positive integer $k$, there exists a unique (up to isomorphism) finite field with $p^k$ elements, denoted $\text{GF}(p^k)$ or $\mathbb{F}_{p^k}$.

Concretely: let $f(x) \in \mathbb{F}_p[x]$ be an irreducible polynomial of degree $k$. Then:

$$\text{GF}(p^k) = \mathbb{F}_p[x]/(f(x)) = \{a_0 + a_1 x + \cdots + a_{k-1}x^{k-1} : a_i \in \mathbb{F}_p\}$$

with all arithmetic done modulo $f(x)$.

Construction — Step by Step

Constructing GF(2³) = GF(8)
  1. Choose an irreducible polynomial of degree 3 over $\mathbb{F}_2$. Check $f(x) = x^3 + x + 1$: $f(0) = 1 \neq 0$, $f(1) = 1+1+1 = 1 \neq 0$. No roots → irreducible over $\mathbb{F}_2$. ✓
  2. Let $\alpha$ be a root: $\alpha^3 + \alpha + 1 = 0$, so $\alpha^3 = \alpha + 1$ (in char 2, $-1 = 1$).
  3. The elements of $\text{GF}(8)$ are all polynomials of degree $\leq 2$ over $\mathbb{F}_2$:
    $\{0, 1, \alpha, \alpha+1, \alpha^2, \alpha^2+1, \alpha^2+\alpha, \alpha^2+\alpha+1\}$ — exactly 8 elements.
  4. To multiply: use the reduction rule $\alpha^3 = \alpha + 1$:
    $\alpha^2 \cdot \alpha^2 = \alpha^4 = \alpha \cdot \alpha^3 = \alpha(\alpha+1) = \alpha^2 + \alpha$.

Why is it unique?

Uniqueness Theorem

Any two finite fields with $p^k$ elements are isomorphic. (The choice of irreducible polynomial $f$ doesn't matter — different choices give isomorphic fields.)

Proof sketch: $\text{GF}(p^k)$ is the splitting field of $x^{p^k} - x$ over $\mathbb{F}_p$. Splitting fields are unique up to isomorphism. Every element $a \in \text{GF}(p^k)$ satisfies $a^{p^k} = a$ (Fermat's little theorem generalized).

What the professor expects

Since this is "not in lectures", they want a complete, precise answer: (1) state that $p$ must be prime and $k \geq 1$, (2) give the construction via $\mathbb{F}_p[x]/(f)$, (3) note uniqueness up to isomorphism, (4) give GF(4) or GF(8) as a concrete example.

Definition
Irreducible Polynomial
Formal Definition

A polynomial $f(x) \in F[x]$ of degree $\geq 1$ is irreducible over $F$ if it cannot be written as $f(x) = g(x) \cdot h(x)$ where $g, h \in F[x]$ and $\deg(g) \geq 1$, $\deg(h) \geq 1$.

Equivalently: $f$ is irreducible if its only divisors in $F[x]$ are units (non-zero constants) and associates (constant multiples of $f$).

How to check irreducibility

  • Degree 1: Always irreducible.
  • Degree 2 or 3: Irreducible $\iff$ no roots in $F$. (If it factors, one factor has degree 1, hence a root.)
  • Degree $\geq 4$: Could factor into two polynomials of degree $\geq 2$ with no roots. Need other methods.
Examples over GF(2) = {0, 1}

Check all degree-3 polynomials by testing $f(0)$ and $f(1)$:

  • $x^3 + x + 1$: $f(0)=1\neq 0$, $f(1)=1+1+1=1\neq 0$ → irreducible ✓
  • $x^3 + x^2 + 1$: $f(0)=1\neq 0$, $f(1)=1+1+1=1\neq 0$ → irreducible ✓
  • $x^3 + 1 = (x+1)(x^2+x+1)$: reducible
  • $x^3 + x^2 + x + 1 = (x+1)^3$: reducible (since $f(1)=0$)
Connection to GF(pᵏ)

Irreducible polynomials are the building blocks of finite fields. For each degree $k$, irreducible polynomials over $\mathbb{F}_p$ exist, and the number of monic irreducible polynomials of degree $k$ over $\mathbb{F}_p$ is $\frac{1}{k}\sum_{d|k} \mu(k/d) p^d$ (by Möbius inversion).

Definition
Primitive Element
Formal Definition

An element $\alpha \in \text{GF}(p^k)$ is a primitive element (or primitive root) if it is a generator of the multiplicative group $\text{GF}(p^k)^*$. That is:

$$\text{ord}(\alpha) = p^k - 1$$

Equivalently: $\{1, \alpha, \alpha^2, \ldots, \alpha^{p^k - 2}\} = \text{GF}(p^k)^*$ — every non-zero element is a power of $\alpha$.

Existence Theorem

Every finite field $\text{GF}(p^k)$ has at least one primitive element. In fact, the multiplicative group $\text{GF}(p^k)^*$ is cyclic of order $p^k - 1$, so it has exactly $\varphi(p^k - 1)$ primitive elements (where $\varphi$ is Euler's totient function).

Primitive polynomial

A monic irreducible polynomial $f(x) \in \mathbb{F}_p[x]$ of degree $k$ is a primitive polynomial if any root of $f$ is a primitive element of $\text{GF}(p^k)$.

Example in GF(7)

$\text{GF}(7)^* = \{1,2,3,4,5,6\}$, order $= 6$. Is $\alpha = 3$ primitive?

$3^1=3$, $3^2=2$, $3^3=6$, $3^4=4$, $3^5=5$, $3^6=1$. Yes! $3$ generates all of $\text{GF}(7)^*$. ✓

$\alpha = 2$: $2^1=2$, $2^2=4$, $2^3=1$. Order 3, not primitive.

Number of primitive elements: $\varphi(6) = \varphi(2)\varphi(3) = 1 \cdot 2 = 2$. Indeed, only $3$ and $5$ are primitive in $\text{GF}(7)$.

Theorem
Properties of Finite Fields
What characteristics does a finite field have?
Complete list of properties
  1. Characteristic is prime: $\text{char}(\text{GF}(p^k)) = p$ for some prime $p$.
  2. Size is prime power: $|\text{GF}(p^k)| = p^k$ for some prime $p$ and $k \geq 1$.
  3. Exists and is unique: For every prime power $q = p^k$, there exists exactly one finite field $\text{GF}(q)$ up to isomorphism.
  4. Multiplicative group is cyclic: $\text{GF}(p^k)^*$ is cyclic of order $p^k - 1$.
  5. Every element satisfies $x^{p^k} = x$: The polynomial $x^{p^k} - x$ splits completely over $\text{GF}(p^k)$ and its roots are exactly the elements of $\text{GF}(p^k)$.
  6. Subfield structure: $\text{GF}(p^d) \subseteq \text{GF}(p^k) \iff d \mid k$.
  7. Frobenius automorphism: The map $\phi: x \mapsto x^p$ is an automorphism of $\text{GF}(p^k)$, and $\text{Gal}(\text{GF}(p^k)/\text{GF}(p)) = \langle \phi \rangle \cong \mathbb{Z}/k\mathbb{Z}$.
Example — Frobenius in GF(4)

$\text{GF}(4) = \mathbb{F}_2[x]/(x^2+x+1)$, elements $\{0, 1, \alpha, \alpha+1\}$ where $\alpha^2 = \alpha+1$.

Frobenius: $\phi(\alpha) = \alpha^2 = \alpha+1$. And $\phi(\alpha+1) = (\alpha+1)^2 = \alpha^2+1 = \alpha$. So $\phi$ swaps $\alpha$ and $\alpha+1$ — this is the Galois group of order 2.

Day 3 — Elliptic Curves
Definition
Elliptic Curve over GF(p^k)
Formal Definition (Short Weierstrass form)

Let $K = \text{GF}(p^k)$ with $p > 3$. An elliptic curve $E$ over $K$ is defined by:

$$E: y^2 = x^3 + ax + b, \quad a, b \in K$$

subject to the non-singularity condition:

$$\Delta = -16(4a^3 + 27b^2) \neq 0$$

The set of points on $E$ over $K$ is:

$$E(K) = \{(x, y) \in K^2 : y^2 = x^3 + ax + b\} \cup \{\mathcal{O}\}$$

where $\mathcal{O}$ is the point at infinity.

For char 2 and char 3

When $p = 2$ or $p = 3$, the short Weierstrass form doesn't work (denominators vanish). Use the general Weierstrass form: $y^2 + a_1 xy + a_3 y = x^3 + a_2 x^2 + a_4 x + a_6$.

Example over GF(7)

$E: y^2 = x^3 + 2x + 3$ over $\mathbb{F}_7$. Check: $\Delta = -16(4 \cdot 8 + 27 \cdot 9) = -16(32+243) = -16 \cdot 275$. Since $275 \equiv 2 \pmod 7$ and $-16 \equiv 5 \pmod 7$, $\Delta \equiv 10 \equiv 3 \neq 0 \pmod 7$. Non-singular ✓.

Hasse's Theorem (bound on number of points)

$$|E(\mathbb{F}_q)| = q + 1 - t, \quad |t| \leq 2\sqrt{q}$$

where $t$ is the trace of Frobenius. So $E$ has roughly $q$ points, within $2\sqrt{q}$.

Definition
Point at Infinity
Projective Coordinates

To include the point at infinity, we work in the projective plane $\mathbb{P}^2(K)$, where points are equivalence classes $[X:Y:Z]$ with $(X,Y,Z) \neq (0,0,0)$ and $[X:Y:Z] = [\lambda X:\lambda Y:\lambda Z]$ for all $\lambda \neq 0$.

An affine point $(x,y)$ corresponds to $[x:y:1]$.

The projective Weierstrass equation is (homogenize by $x = X/Z$, $y = Y/Z$):

$$Y^2 Z = X^3 + aXZ^2 + bZ^3$$

Setting $Z = 0$: $0 = X^3$, so $X = 0$. The only solution with $Z=0$ is $[0:1:0]$.

The point at infinity is $\mathcal{O} = [0:1:0]$.

Role of O

$\mathcal{O}$ is the identity element of the group law $(E(K), +)$:

  • $P + \mathcal{O} = \mathcal{O} + P = P$ for all $P \in E(K)$
  • $P + (-P) = \mathcal{O}$ where $-P = (x, -y)$ for $P = (x,y)$

Geometrically: the line through $P$ and $-P$ is vertical; it meets the curve at $\mathcal{O}$ as the "third point at infinity".

Exam tip

A perfect answer explains: why we need projective coordinates, the homogeneous equation, the specific solution $[0:1:0]$, and why $\mathcal{O}$ is the group identity.

Algorithm
Addition of Points on an Elliptic Curve

$(E(K), +)$ forms an abelian group. The addition uses the chord-and-tangent method.

Group law — all cases

Let $P = (x_1, y_1)$ and $Q = (x_2, y_2)$ be points on $E: y^2 = x^3 + ax + b$.

Case 1: $P = \mathcal{O}$. $\mathcal{O} + Q = Q$.

Case 2: $Q = \mathcal{O}$. $P + \mathcal{O} = P$.

Case 3: $x_1 = x_2$ and $y_1 = -y_2$ (i.e., $Q = -P$). $P + Q = \mathcal{O}$. (Vertical line.)

Case 4: $P \neq Q$, $P \neq -Q$ (chord, generic).

$$\lambda = \frac{y_2 - y_1}{x_2 - x_1}, \quad x_3 = \lambda^2 - x_1 - x_2, \quad y_3 = \lambda(x_1 - x_3) - y_1$$

Case 5: $P = Q$ (tangent, doubling).

$$\lambda = \frac{3x_1^2 + a}{2y_1}, \quad x_3 = \lambda^2 - 2x_1, \quad y_3 = \lambda(x_1 - x_3) - y_1$$

(This case requires $y_1 \neq 0$; if $y_1 = 0$ then $2P = \mathcal{O}$.)

Where do these formulas come from?

Chord case: The line through $P$ and $Q$ is $y = \lambda x + \mu$. Substitute into $y^2 = x^3 + ax + b$: $(\lambda x + \mu)^2 = x^3 + ax + b$. This gives a cubic $x^3 - \lambda^2 x^2 + \ldots = 0$ whose three roots are $x_1, x_2, x_3$ (by Vieta's: $x_1 + x_2 + x_3 = \lambda^2$). So $x_3 = \lambda^2 - x_1 - x_2$. Then $y_3 = -(\lambda x_3 + \mu) = \lambda(x_1 - x_3) - y_1$ (we negate because the actual sum is the reflection).

Tangent case: Implicit differentiation of $y^2 = x^3 + ax + b$ gives $2y\,dy = (3x^2+a)\,dx$, so slope $\lambda = (3x_1^2+a)/(2y_1)$.

Numerical Example in GF(7)

$E: y^2 = x^3 + 2x + 3$ over $\mathbb{F}_7$. Let $P = (3, 5)$, $Q = (3, 2)$.

Check: $y_1 + y_2 = 5 + 2 = 7 \equiv 0 \pmod 7$, so $Q = -P$. Therefore $P + Q = \mathcal{O}$.

Now double $P = (3,5)$: $\lambda = (3 \cdot 9 + 2)/(2 \cdot 5) = 29/10 \equiv 1/3 \equiv 5 \pmod 7$ (since $3 \cdot 5 = 15 \equiv 1$). $x_3 = 25 - 6 = 19 \equiv 5$. $y_3 = 5(3-5) - 5 = -15 \equiv -15+21 = 6$. So $2P = (5, 6)$.

Definition
Divisor on an Elliptic Curve
Formal Definition

A divisor $D$ on an elliptic curve $E$ is a formal finite $\mathbb{Z}$-linear combination of points on $E$:

$$D = \sum_{P \in E(\bar{K})} n_P [P], \quad n_P \in \mathbb{Z}, \text{ almost all } n_P = 0$$

The set of all divisors forms an abelian group $\text{Div}(E)$ under addition.

The degree of a divisor is:

$$\deg(D) = \sum_{P} n_P \in \mathbb{Z}$$

The sum of a divisor is:

$$\text{sum}(D) = \sum_{P} n_P \cdot P \in E(K)$$

(where $\cdot$ and $+$ are the elliptic curve group operations)

Principal divisors

Principal divisor of a function

For a rational function $f$ on $E$ (not identically zero), its divisor is:

$$\text{div}(f) = \sum_P \text{ord}_P(f) [P]$$

where $\text{ord}_P(f)$ is the order of vanishing of $f$ at $P$ (positive = zero, negative = pole).

Key fact: $\deg(\text{div}(f)) = 0$ for any rational function $f$.

Example

The function $f(x,y) = x - x_0$ (a vertical line through $(x_0, y_0)$) has zeros at $(x_0, y_0)$ and $(x_0, -y_0)$ and a double pole at $\mathcal{O}$:

$$\text{div}(x - x_0) = [(x_0, y_0)] + [(x_0, -y_0)] - 2[\mathcal{O}]$$

Degree: $1 + 1 - 2 = 0$ ✓

Key theorem (used in cryptography)

A divisor $D = \sum n_P [P]$ with $\deg(D) = 0$ is principal (i.e., $D = \text{div}(f)$ for some $f$) if and only if $\text{sum}(D) = \mathcal{O}$.

Day 4 — Lattices & Post-Quantum Cryptography
Definition
Lattice (Grid)
Formal Definition

A lattice $\mathcal{L}$ is a discrete additive subgroup of $\mathbb{R}^m$. Equivalently, given linearly independent vectors $\mathbf{b}_1, \ldots, \mathbf{b}_n \in \mathbb{R}^m$ (the basis), the lattice is:

$$\mathcal{L}(\mathbf{b}_1, \ldots, \mathbf{b}_n) = \left\{ \sum_{i=1}^n a_i \mathbf{b}_i : a_i \in \mathbb{Z} \right\} = \{B\mathbf{a} : \mathbf{a} \in \mathbb{Z}^n\}$$

where $B = [\mathbf{b}_1 | \cdots | \mathbf{b}_n]$ is the basis matrix.

The determinant (or volume) of the lattice is:

$$\det(\mathcal{L}) = \sqrt{\det(B^T B)} = |\det(B)| \quad (\text{when } n = m)$$

This is the volume of the fundamental parallelepiped $\mathcal{F} = \{B\mathbf{x} : \mathbf{x} \in [0,1)^n\}$.

Example

$\mathbf{b}_1 = (1, 0)$, $\mathbf{b}_2 = (0, 1)$: integer lattice $\mathbb{Z}^2$.

$\mathbf{b}_1 = (2, 0)$, $\mathbf{b}_2 = (1, 3)$: $\det = 6$, a "stretched" sublattice of $\mathbb{Z}^2$.

Key Facts
  • A lattice has infinitely many bases (related by unimodular matrices $U$ with $\det(U) = \pm 1$).
  • All bases of the same lattice have the same $|\det|$.
  • A good basis has short, nearly orthogonal vectors. A bad basis has long, nearly parallel vectors. Same lattice, very different appearances!
Definition
Shortest Vector Problem (SVP) & Closest Vector Problem (CVP)
SVP — Shortest Vector Problem

Given a basis $B$ of a lattice $\mathcal{L}$, find a shortest non-zero vector in $\mathcal{L}$:

$$\text{SVP: find } \mathbf{v} \in \mathcal{L} \setminus \{\mathbf{0}\} \text{ minimizing } \|\mathbf{v}\|$$

The length of the shortest vector is denoted $\lambda_1(\mathcal{L})$.

CVP — Closest Vector Problem

Given a basis $B$ of a lattice $\mathcal{L}$ and a target vector $\mathbf{t} \in \mathbb{R}^m$ (not necessarily in $\mathcal{L}$), find the closest lattice vector to $\mathbf{t}$:

$$\text{CVP: find } \mathbf{v} \in \mathcal{L} \text{ minimizing } \|\mathbf{t} - \mathbf{v}\|$$
Hardness
  • SVP is NP-hard (under randomized reductions) in the exact case.
  • CVP is NP-hard even to approximate within constant factors.
  • Even approximate versions (SVP$_\gamma$, CVP$_\gamma$) for polynomial $\gamma$ are believed hard — this is the foundation of lattice-based cryptography (NTRU, Kyber, Dilithium).
Exam tip

The key distinction: SVP looks for the short vector in the lattice itself; CVP looks for the lattice vector closest to an external target. Both are computationally hard with a bad (long/skewed) basis, but easy with a good (short/orthogonal) basis.

Definition
Gaussian Expected Shortest Vector Length
Gaussian Heuristic

For a "typical" (random) lattice $\mathcal{L}$ of dimension $n$ and determinant $\det(\mathcal{L})$, the expected length of the shortest non-zero vector is approximately:

$$\lambda_1(\mathcal{L}) \approx \sqrt{\frac{n}{2\pi e}} \cdot \det(\mathcal{L})^{1/n}$$

or equivalently (using the volume of the unit ball $V_n = \pi^{n/2}/\Gamma(n/2+1)$):

$$\lambda_1(\mathcal{L}) \approx \left(\frac{\Gamma(n/2+1)}{V_n}\right)^{1/n} \cdot \det(\mathcal{L})^{1/n} = \sqrt{\frac{n}{2\pi e}} \cdot \det(\mathcal{L})^{1/n}$$

Intuition

Think of it probabilistically: the number of lattice points in a ball of radius $r$ is approximately $\text{Vol}(B_r^n) / \det(\mathcal{L})$. The shortest vector is roughly where this count first reaches 1:

$$V_n r^n / \det(\mathcal{L}) \approx 1 \implies r \approx (V_n^{-1} \det(\mathcal{L}))^{1/n}$$
Example for n = 100

For the standard lattice $\mathbb{Z}^{100}$ ($\det = 1$): $\lambda_1 \approx \sqrt{100/(2\pi e)} \approx \sqrt{5.85} \approx 2.4$. But $\mathbb{Z}^{100}$ has shortest vector of length 1 — the heuristic is only valid for "random" lattices, not structured ones.

Warning

This is a heuristic, not a theorem. For specific lattices (like $\mathbb{Z}^n$), the actual shortest vector can be much shorter. In cryptographic applications, security is based on hard instances where the Gaussian heuristic approximately holds.

Algorithm
NTRU Encryption System
Parameters

NTRU works in the polynomial ring $R = \mathbb{Z}[x]/(x^N - 1)$, where arithmetic is mod $(x^N - 1)$ (convolution product). Elements are polynomials of degree $< N$.

  • $N$ — prime (degree of ring)
  • $p$ — small prime (e.g., 3) — for inner reduction
  • $q$ — large integer (e.g., 2048) — for outer reduction. Must have $\gcd(p, q) = 1$ and $q \gg p$
  • $d_f, d_g, d_r$ — parameters controlling the "smallness" of key polynomials

Key Generation

Step-by-step key generation
  1. Choose a small polynomial $f \in R$ with $d_f$ coefficients equal to $+1$, $d_f - 1$ equal to $-1$, rest $0$.
  2. Ensure $f$ is invertible mod $p$: compute $f_p = f^{-1} \pmod{p}$ in $R$.
  3. Ensure $f$ is invertible mod $q$: compute $f_q = f^{-1} \pmod{q}$ in $R$.
  4. Choose a small polynomial $g \in R$ similarly.
  5. Compute the public key: $h = p \cdot f_q \cdot g \pmod{q}$.
  6. Private key: $(f, f_p)$. Public key: $h$.

Encryption

Encrypt message m ∈ R (coefficients in {0,…,p-1})
  1. Choose a random small "blinding" polynomial $r$ (ephemeral).
  2. Compute ciphertext: $e = r \cdot h + m \pmod{q}$.

Decryption

Decrypt e using private key f
  1. Compute $a = f \cdot e \pmod{q}$, centering coefficients in $(-q/2, q/2]$.
  2. Reduce mod $p$: $b = a \pmod{p}$.
  3. Recover message: $m = f_p \cdot b \pmod{p}$.
Theorem + Proof
NTRU Correctness Proof
Theorem

Under the smallness assumption, the NTRU decryption of $e = r \cdot h + m \pmod{q}$ returns the original message $m$.

Proof — Step by Step

Step 1: Expand $a = f \cdot e \pmod{q}$.

Substitute $e = r \cdot h + m$ and $h = p \cdot f_q \cdot g$:

$$a = f \cdot e = f \cdot (r \cdot h + m) = f \cdot r \cdot h + f \cdot m \pmod{q}$$ $$= f \cdot r \cdot (p \cdot f_q \cdot g) + f \cdot m \pmod{q}$$ $$= p \cdot r \cdot (f \cdot f_q) \cdot g + f \cdot m \pmod{q}$$

Step 2: Use $f \cdot f_q \equiv 1 \pmod{q}$.

$$a \equiv p \cdot r \cdot g + f \cdot m \pmod{q}$$

Step 3: Smallness assumption (key step).

The coefficients of $p \cdot r \cdot g + f \cdot m$ are small (bounded by some value $< q/2$) because $r$, $g$, $f$, $m$ all have small coefficients. Therefore, when we center the coefficients mod $q$ into $(-q/2, q/2]$, we get:

$$a = p \cdot r \cdot g + f \cdot m \quad \text{(as honest integer polynomial, no mod)}$$

Step 4: Reduce $a$ mod $p$.

$$a \equiv p \cdot r \cdot g + f \cdot m \equiv f \cdot m \pmod{p}$$

(since $p \cdot r \cdot g \equiv 0 \pmod{p}$)

Step 5: Apply $f_p = f^{-1} \pmod p$.

$$f_p \cdot a \equiv f_p \cdot f \cdot m \equiv m \pmod{p} \quad \square$$
When does decryption fail?

If the smallness assumption is violated (coefficients of $p \cdot r \cdot g + f \cdot m$ exceed $q/2$ in absolute value), then the reduction mod $q$ wraps around and the equality in Step 3 fails. This is called a decryption failure. Parameters must be chosen to make this probability negligible.

Exam tip — the proof hinges on these two equalities
  1. $f \cdot f_q \equiv 1 \pmod{q}$ (by definition of $f_q$)
  2. $f \cdot f_p \equiv 1 \pmod{p}$ (by definition of $f_p$)

And one crucial assumption: coefficients stay small enough to pass through mod $q$ without wraparound.

Day 5 — Gröbner Bases & MQ Problem
Definition
Gröbner Basis

Prerequisites

Monomial order

A monomial order $\prec$ on $K[x_1,\ldots,x_n]$ is a total order on monomials such that: (1) $1 \prec m$ for all non-trivial monomials, (2) if $m_1 \prec m_2$ then $m \cdot m_1 \prec m \cdot m_2$. Common orders: lexicographic (lex), graded lex (glex), graded reverse lex (grevlex).

Leading term

For $f \in K[x_1,\ldots,x_n]$ with monomial order $\prec$: $\text{LT}(f)$ is the leading (largest) term, $\text{LM}(f)$ is the leading monomial, $\text{LC}(f)$ is the leading coefficient.

Formal Definition of Gröbner Basis

Let $I \subseteq K[x_1, \ldots, x_n]$ be a polynomial ideal. A finite set $G = \{g_1, \ldots, g_t\} \subset I$ is a Gröbner basis of $I$ (with respect to monomial order $\prec$) if:

$$\langle \text{LT}(g_1), \ldots, \text{LT}(g_t) \rangle = \langle \text{LT}(f) : f \in I \setminus \{0\} \rangle$$

In words: the ideal of leading terms of $G$ equals the ideal of leading terms of all of $I$.

Equivalent characterizations

Equivalent conditions

$G$ is a Gröbner basis of $I$ iff any of these hold:

  • Every $f \in I$ has its leading term divisible by some $\text{LT}(g_i)$.
  • Every $f \in I$ reduces to $0$ modulo $G$ (i.e., the remainder on division by $G$ is $0$).
  • Every $S$-polynomial $S(g_i, g_j)$ reduces to $0$ modulo $G$ (Buchberger's criterion — see Day 5).

Why does this matter?

A Gröbner basis is the polynomial ideal analogue of a row-echelon basis for a linear system. It allows: solving polynomial systems, deciding ideal membership, eliminating variables.

Example

$I = \langle x^2 - 1, xy - 1 \rangle \subset \mathbb{Q}[x,y]$ with lex order $x \succ y$.

Compute $S(x^2-1, xy-1) = y(x^2-1) - x(xy-1) = -y + x = x - y$. Add $x - y$ to basis. Now $G = \{x^2-1, xy-1, x-y\}$. Reduce: $x-y$ reduces $xy-1$ to $y^2-1$. Final Gröbner basis: $\{x-y, y^2-1\}$. Solution: $y^2=1$ so $y=\pm 1$, $x=y$.

Definition
MQ Problem (Multivariate Quadratic Problem)
Formal Definition

The MQ problem is: given $m$ quadratic polynomials $f_1, \ldots, f_m \in \mathbb{F}_q[x_1, \ldots, x_n]$ (each of degree $\leq 2$), find a common solution $(a_1, \ldots, a_n) \in \mathbb{F}_q^n$ such that:

$$f_1(a_1, \ldots, a_n) = f_2(a_1, \ldots, a_n) = \cdots = f_m(a_1, \ldots, a_n) = 0$$

The general form of each polynomial is:

$$f_i(x_1,\ldots,x_n) = \sum_{1 \leq j \leq k \leq n} \alpha_{ijk} x_j x_k + \sum_{j=1}^n \beta_{ij} x_j + \gamma_i$$
Hardness

The MQ problem is NP-complete over any finite field, and is believed to be hard even for quantum computers. It is the basis for multivariate public-key cryptography (e.g., Rainbow, HFEv-, GeMSS schemes).

Connection to Gröbner bases

Solving the MQ problem is equivalent to computing the Gröbner basis of the ideal $I = \langle f_1, \ldots, f_m \rangle + \langle x_1^q - x_1, \ldots, x_n^q - x_n \rangle$ (field equations ensure solutions lie in $\mathbb{F}_q$). The Buchberger algorithm (or faster F4/F5) computes this basis, but worst-case complexity is doubly exponential in $n$.

Theorem
Buchberger's Criterion
S-polynomial definition (prerequisite)

For $f, g \in K[x_1,\ldots,x_n]$ with $\text{lcm}(\text{LM}(f), \text{LM}(g)) = L$:

$$S(f, g) = \frac{L}{\text{LT}(f)} \cdot f - \frac{L}{\text{LT}(g)} \cdot g$$

The S-polynomial cancels the leading terms of $f$ and $g$. It's designed so that $S(f,g)$ has lower leading term than both $f$ and $g$.

Buchberger's Criterion (Theorem)

A finite set $G = \{g_1, \ldots, g_t\} \subset K[x_1,\ldots,x_n]$ is a Gröbner basis for the ideal $I = \langle G \rangle$ if and only if:

$$\text{for all } i \neq j: \quad \overline{S(g_i, g_j)}^G = 0$$

i.e., every S-polynomial $S(g_i, g_j)$ reduces to zero on division by $G$.

Proof sketch

($\Rightarrow$): If $G$ is a Gröbner basis then every polynomial in $\langle G \rangle$ has remainder $0$ modulo $G$. Since $S(g_i, g_j) \in \langle G \rangle = I$, it reduces to $0$.

($\Leftarrow$): Suppose all S-polynomials reduce to $0$. We must show every $f \in I$ reduces to $0$ modulo $G$. Write $f = \sum h_i g_i$ and argue (by a leading term argument with the "representation theorem") that any cancellation of leading terms can be re-expressed using S-polynomial reductions, all of which are $0$ by assumption. $\square$ (Full proof via Buchberger's syzygy lemma.)

Example

$G = \{f_1 = x^2 - 1, f_2 = xy - 1\}$ in $\mathbb{Q}[x,y]$, lex $x \succ y$.

$\text{LM}(f_1) = x^2$, $\text{LM}(f_2) = xy$, $\text{lcm} = x^2 y$.

$S(f_1, f_2) = \frac{x^2 y}{x^2} f_1 - \frac{x^2 y}{xy} f_2 = y(x^2-1) - x(xy-1) = x^2 y - y - x^2 y + x = x - y$.

Remainder of $x-y$ on division by $\{x^2-1, xy-1\}$: leading term $x$, not divisible by $x^2$ or $xy$. So remainder $= x - y \neq 0$. → $G$ is NOT a Gröbner basis. We must add $x-y$ to $G$.

Algorithm
Buchberger's Algorithm (Pseudocode)

The algorithm incrementally builds a Gröbner basis by adding non-zero S-polynomial remainders until all S-polynomials reduce to zero.

Input:  $F = \{f_1, \ldots, f_s\}$ — generators of ideal $I$, monomial order $\prec$
Output: $G$ — a Gröbner basis of $I$

BUCHBERGER($F$):
  $G \leftarrow F$
  $B \leftarrow \{(g_i, g_j) : g_i, g_j \in G,\ i < j\}$  // all pairs to process

  while $B \neq \emptyset$ do
    pick any $(g_i, g_j) \in B$
    $B \leftarrow B \setminus \{(g_i, g_j)\}$

    $S \leftarrow S(g_i, g_j)$           // compute S-polynomial
    $r \leftarrow$ REDUCE$(S, G)$         // remainder on division by G

    if $r \neq 0$ then
      $B \leftarrow B \cup \{(r, g) : g \in G\}$  // pair r with all current basis elements
      $G \leftarrow G \cup \{r\}$                 // add r to basis
    end if
  end while

  return $G$

// Note: G is a Gröbner basis but may not be minimal or reduced.
// Optional: apply interreduction to get the unique reduced Gröbner basis.

REDUCE subroutine

REDUCE$(f, G = \{g_1, \ldots, g_t\})$:
  $r \leftarrow 0$
  $p \leftarrow f$
  while $p \neq 0$ do
    if $\exists\, g_i \in G$ such that $\text{LM}(g_i) \mid \text{LM}(p)$ then
      $p \leftarrow p - \frac{\text{LT}(p)}{\text{LT}(g_i)} \cdot g_i$   // reduce leading term
    else
      $r \leftarrow r + \text{LT}(p)$   // LT cannot be reduced, save it
      $p \leftarrow p - \text{LT}(p)$
    end if
  end while
  return $r$
Termination & Correctness
  • Termination: Every iteration either pops from $B$ without growing $G$, or adds an element whose leading monomial is strictly greater (in the ideal of leading monomials). By the ascending chain condition (Dickson's lemma), this must terminate.
  • Correctness: By Buchberger's criterion: the algorithm terminates exactly when all S-polynomials reduce to $0$, which is the criterion for $G$ being a Gröbner basis.
Trace through example

$F = \{f_1 = x^2 - 1, f_2 = xy - 1\}$, lex with $x \succ y$.

$B = \{(f_1, f_2)\}$. Pick $(f_1, f_2)$: $S = x - y$. $\text{REDUCE}(x-y, \{f_1,f_2\})$: LM$(x-y) = x$; $x$ not divisible by $x^2$ or $xy$. Remainder $= x - y \neq 0$. Add $g_3 = x-y$. $G = \{f_1, f_2, g_3\}$, $B = \{(f_1, g_3), (f_2, g_3)\}$.

Process $(f_1, g_3)$: $S(x^2-1, x-y) = (x^2-1) - x(x-y) = xy - 1 = f_2$. REDUCE$(f_2, G)$: $xy - 1$ divided by $xy-1 = f_2$ reduces to $0$. No new element.

Process $(f_2, g_3)$: $S(xy-1, x-y) = y(x-y) - x(xy-1)/(y)$... LCM$(xy, x) = xy$. $S = (xy/xy)(xy-1) - (xy/x)(x-y) = xy-1 - y(x-y) = xy-1-xy+y^2 = y^2-1$. REDUCE$(y^2-1, G)$: LM $= y^2$, not divisible by $x^2, xy, x$. So $r = y^2-1$. Add $g_4 = y^2-1$.

Continue… eventually terminates with Gröbner basis $G = \{x-y, y^2-1\}$ (after reduction).

Exam tip — pseudocode must contain
  1. Initialize $G \leftarrow F$, $B \leftarrow$ all pairs
  2. While loop: pick pair, compute S-polynomial, reduce modulo $G$
  3. If remainder $\neq 0$: add to $G$, add new pairs to $B$
  4. Return $G$
Day 6 — Discrete Logarithm Algorithms
Algorithm
Index Calculus
Solves the discrete logarithm problem in Z_p*
Problem Statement

Given a prime $p$, a generator $g$ of $\mathbb{Z}_p^*$, and an element $h \in \mathbb{Z}_p^*$, find $x$ such that $g^x \equiv h \pmod{p}$.

Core Idea: Factor Base

The algorithm exploits the fact that many random powers of $g$ factor into small primes. A number is $B$-smooth if all its prime factors are $\leq B$.

Input:  prime $p$, generator $g$, target $h$, smoothness bound $B$
Output: $x = \log_g h \pmod{p-1}$

═══ PHASE 1: Precomputation of discrete logs of primes ═══

$\mathcal{B} = \{p_1, p_2, \ldots, p_t\}$  // factor base: all primes ≤ B

COLLECT_RELATIONS():
  $\text{relations} \leftarrow []$
  while $|\text{relations}| < t + 1$ do
    choose random $k \in \{1, \ldots, p-2\}$
    compute $v \leftarrow g^k \bmod p$
    if $v$ is $\mathcal{B}$-smooth, say $v = p_1^{e_1} \cdots p_t^{e_t}$  then
      record: $k \equiv e_1 L_1 + e_2 L_2 + \cdots + e_t L_t \pmod{p-1}$
      // where L_i = log_g(p_i) are unknowns
      append to relations
    end if
  end while

SOLVE_LINEAR_SYSTEM():
  solve the system of $\geq t$ equations for $L_1, \ldots, L_t \pmod{p-1}$
  // using linear algebra over Z/(p-1)Z
  return $\{L_1, \ldots, L_t\}$   // logs of all factor base primes

═══ PHASE 2: Individual logarithm for h ═══

FIND_LOG($h$):
  loop
    choose random $s \in \{0, \ldots, p-2\}$
    compute $w \leftarrow h \cdot g^s \bmod p$
    if $w$ is $\mathcal{B}$-smooth, say $w = p_1^{f_1} \cdots p_t^{f_t}$  then
      // log_g(w) = log_g(h) + s (mod p-1)
      // log_g(w) = f_1*L_1 + ... + f_t*L_t (mod p-1)
      $x \leftarrow f_1 L_1 + \cdots + f_t L_t - s \pmod{p-1}$
      return $x$
    end if
  end loop

Why this works

Correctness argument

Phase 1: When $g^k \equiv p_1^{e_1} \cdots p_t^{e_t} \pmod{p}$, taking $\log_g$ of both sides gives: $k \equiv e_1 \log_g p_1 + \cdots + e_t \log_g p_t \pmod{p-1}$. This is a linear equation in the unknowns $L_i = \log_g p_i$. With $t+1$ independent equations, we can solve for all $L_i$.

Phase 2: When $h \cdot g^s \equiv p_1^{f_1} \cdots p_t^{f_t} \pmod{p}$, taking $\log_g$: $\log_g h + s \equiv f_1 L_1 + \cdots + f_t L_t \pmod{p-1}$. So $\log_g h \equiv \sum f_i L_i - s \pmod{p-1}$.

Complexity

With optimal $B = L_p[1/2, 1/\sqrt{2}]$ (where $L_p[\alpha, c] = e^{c (\log p)^\alpha (\log\log p)^{1-\alpha}}$), the running time is subexponential:

$$\text{Time} = L_p\left[\frac{1}{2}, \sqrt{2}\right] = e^{\sqrt{2} \cdot \sqrt{\log p \log\log p}}$$

This is why DLP in $\mathbb{Z}_p^*$ requires $p$ of at least 2048 bits for security.

Exam tip — pseudocode must include
  1. Factor base $\mathcal{B}$
  2. Phase 1: random $k$, compute $g^k \bmod p$, check smoothness, build linear system, solve for $L_i$
  3. Phase 2: random $s$, compute $h \cdot g^s \bmod p$, check smoothness, compute $x = \sum f_i L_i - s$
Theorem + Proof
Pohlig-Hellman Algorithm
Prove that it solves g^x = h
Statement

Let $G$ be a cyclic group of order $n = p_1^{e_1} p_2^{e_2} \cdots p_r^{e_r}$, with generator $g$ and target $h = g^x$. The Pohlig-Hellman algorithm finds $x \pmod{n}$ by reducing to smaller discrete logarithm problems in subgroups of prime power order, then combining via the Chinese Remainder Theorem.

Main idea

Instead of solving $g^x = h$ in the full group of order $n$, solve for $x \bmod p_i^{e_i}$ separately for each prime power factor, then use CRT to recover $x \bmod n$.

Input:  Group $G$ of order $n = \prod p_i^{e_i}$, generator $g$, $h = g^x$
Output: $x \bmod n$

POHLIG_HELLMAN($g, h, n$):
  factor $n = p_1^{e_1} \cdots p_r^{e_r}$
  
  for each prime power $q = p_i^{e_i}$:
    // Step 1: project to subgroup of order q
    $g_q \leftarrow g^{n/q}$         // has order exactly q = p^e
    $h_q \leftarrow h^{n/q}$         // = g^(x · n/q) = g_q^x
    
    // Step 2: solve g_q^{x_i} = h_q using baby-step-giant-step
    // or by building x mod p^e digit by digit:
    
    $x_i \leftarrow$ DLP_PRIME_POWER($g_q, h_q, p, e$)
    // x_i is x mod p^e
  
  // Step 3: CRT to combine all x mod p_i^{e_i}
  $x \leftarrow$ CRT($[x_1, \ldots, x_r], [p_1^{e_1}, \ldots, p_r^{e_r}]$)
  return $x \bmod n$


DLP_PRIME_POWER($g_q, h_q, p, e$):
  // Solve g_q^x = h_q where ord(g_q) = p^e
  // Write x = a_0 + a_1*p + a_2*p^2 + ... + a_{e-1}*p^{e-1} (base p)
  $\gamma \leftarrow g_q^{p^{e-1}}$    // has order p (a primitive p-th root)
  $x \leftarrow 0$
  $\tilde{h} \leftarrow h_q$
  
  for $k = 0$ to $e - 1$:
    $\delta \leftarrow \tilde{h}^{p^{e-1-k}}$   // = gamma^{a_k}, extract next digit
    $a_k \leftarrow$ DLOG$(\gamma, \delta, p)$ // DLP of order p (BSGS, O(sqrt(p)))
    $x \leftarrow x + a_k \cdot p^k$
    $\tilde{h} \leftarrow \tilde{h} \cdot g_q^{-a_k \cdot p^k}$  // peel off digit a_k
  
  return $x$
Correctness Proof — prove that it solves g^x = h

Claim: $g_q = g^{n/q}$ has order exactly $q = p^e$.

$(g_q)^q = g^{n/q \cdot q} = g^n = e_G$ (identity). And for any proper divisor $d \mid q$ with $d < q$: $(g_q)^d = g^{n/q \cdot d}$. Since $g$ has order $n$ and $n/q \cdot d < n$ (because $d < q$), and $n \nmid n/q \cdot d$ (since $q \nmid q/d$ when $p \mid q/d$), this is not the identity. So $\text{ord}(g_q) = q$. ✓

Claim: $h_q = g_q^x \pmod{n}$, so $x$ modulo $q$ is the DLP of $h_q$ to base $g_q$.

$h_q = h^{n/q} = (g^x)^{n/q} = (g^{n/q})^x = g_q^x$. ✓

Therefore $x_i = x \bmod p_i^{e_i}$ (since $g_q$ has order $p_i^{e_i}$).

CRT step: We have $x \equiv x_i \pmod{p_i^{e_i}}$ for each $i$. Since the $p_i^{e_i}$ are pairwise coprime and their product is $n$, by the Chinese Remainder Theorem there is a unique $x \in \{0, \ldots, n-1\}$ satisfying all these congruences simultaneously. That unique solution is the $x$ we seek. $\square$

Digit extraction in DLP_PRIME_POWER: Write $x \bmod p^e = a_0 + a_1 p + \cdots + a_{e-1} p^{e-1}$. Then $\tilde{h}^{p^{e-1}} = g_q^{x \cdot p^{e-1}} = g_q^{(a_0 + a_1 p + \cdots) p^{e-1}} = g_q^{a_0 p^{e-1}} = \gamma^{a_0}$ (higher terms become $g_q^{p^e} = e$). So $a_0 = \log_\gamma \tilde{h}^{p^{e-1}}$ in a group of order $p$. Inductively recover all digits. $\square$

Complexity

Total time: $O\left(\sum_{i=1}^r e_i \left(\log n + \sqrt{p_i}\right)\right)$. Pohlig-Hellman is efficient when all prime factors $p_i$ of $n$ are small. This is why cryptographic groups must have order with a large prime factor — e.g., use a prime-order subgroup.

Theorem + Proof
Index of Coincidence (IOC)
Formal Definition

Let $T = t_1 t_2 \cdots t_n$ be a text of length $n$ over a $c$-letter alphabet. Let $f_i$ be the frequency of the $i$-th letter. The Index of Coincidence is:

$$\text{IC}(T) = \frac{\sum_{i=0}^{c-1} f_i(f_i - 1)}{n(n-1)}$$

Equivalently, IC is the probability that two randomly chosen letters from $T$ are the same:

$$\text{IC}(T) = \Pr[\text{two random letters from } T \text{ are equal}]$$

Key Values for English (c = 26)

Text typeIC valueExplanation
English plaintext$\approx 0.065$Non-uniform letter distribution
Random (uniform) text$\approx 0.0385 = 1/26$All letters equally likely
Vigenère, key length $d$$\approx \frac{1}{d} \cdot 0.065 + \frac{d-1}{d} \cdot 0.0385$Mix of $d$ Caesar ciphers
Theorem: IC of English (what it proves)

For a language where letter $i$ has probability $p_i$, the expected IC of a long text is:

$$E[\text{IC}] = \sum_{i=0}^{c-1} p_i^2$$

For English: $\sum_{i} p_i^2 \approx 0.065$. For uniform: $\sum_i (1/c)^2 = 1/c \approx 0.038$.

Proof that IC applies (derivation)

Step 1: Count the ways to pick 2 letters of the same type $i$: $\binom{f_i}{2} = \frac{f_i(f_i-1)}{2}$.

Step 2: Total ways to pick any 2 letters: $\binom{n}{2} = \frac{n(n-1)}{2}$.

Step 3: Probability that two chosen letters are both type $i$:

$$\text{IC} = \frac{\text{number of matching pairs}}{\text{total pairs}} = \frac{\sum_i \binom{f_i}{2}}{\binom{n}{2}} = \frac{\sum_i f_i(f_i-1)}{n(n-1)}$$

Step 4: For large $n$, $f_i \approx n p_i$, so:

$$\text{IC} \approx \frac{\sum_i n p_i \cdot (n p_i - 1)}{n(n-1)} \approx \sum_i p_i^2$$

Step 5 (Vigenère): With key length $d$, the ciphertext has $d$ "streams", each encrypted with a different Caesar shift. Two random letters from the same stream agree with probability $\sum p_i^2 \approx 0.065$; two letters from different streams agree with probability $1/26 \approx 0.038$. The overall IC is a weighted mix:

$$\text{IC}_{\text{Vig}} \approx \frac{1}{d} \cdot 0.065 + \frac{d-1}{d} \cdot 0.038$$

Solving for $d$ given the observed IC lets us estimate the key length. $\square$

Application to Kasiski / Vigenère analysis

Observe IC of ciphertext ≈ 0.052. Then:

$$0.052 = \frac{0.065}{d} + \frac{d-1}{d} \cdot 0.038 = \frac{0.038 d + 0.027}{d} = 0.038 + \frac{0.027}{d}$$ $$0.014 = \frac{0.027}{d} \implies d \approx 1.9 \approx 2$$

So the key length is likely 2.

Exam tip — "prove that it applies"

The proof must show: (1) combinatorial definition of IC, (2) it equals $\sum p_i^2$ in the limit, (3) this value distinguishes natural language ($0.065$) from random text ($1/c$), and (4) for Vigenère the IC is the weighted average allowing key length estimation.
